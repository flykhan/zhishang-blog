    frontmatter 说明

    文件开头可选的 YAML 区块：

    {% raw %}---
title: 文章标题
date: 2022-10-18T15:33:14+08:00
tags: [技术, 随笔]
slug: hello-world
summary: 一句话摘要
status: published
---{% endraw %}
    • title：缺省时依次回退到正文第一个 # 标题、文件名。
    • date：支持 ISO 8601 与常见日期格式，缺省使用导入时间。
    • tags：YAML 列表或逗号分隔字符串，可与默认标签合并。
    • slug：缺省时由标题自动生成；重复时按冲突策略处理。
    • status / draft：优先于上方「发布状态」选项。
    • summary：缺省时自动截取正文开头。

    导入限制

    • 支持扩展名：.md、.markdown、.txt。
    • 单个文件不超过 5 MB，一次最多 50 个。
    • 每篇文件创建或更新一篇文章，不会删除现有内容。
    • 正文图片请使用可公开访问的 URL，或先上传到站点静态目录。
